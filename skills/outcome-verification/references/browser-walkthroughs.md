# Browser walkthroughs

Use Playwright against a running test environment with synthetic data. Cover operator journeys from the approved experience, not a redesigned UI. Capture trace-on-failure, screenshots at named checkpoints, console/page errors and failed network calls. Pair visual checks with semantic assertions, accessibility checks, and backend evidence IDs. Avoid brittle pixel snapshots as the only proof. Do not click destructive production controls or use live credentials.
