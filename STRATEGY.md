# Strategy

1. Audit and pin tested modules from Rally, EARS and VentureOS. Prefer adaptation over copying full architectures.
2. Bootstrap one Builder, one independent Reviewer, one deterministic Controller, one project adapter.
3. Demonstrate actual CLI execution and restart recovery before dashboards or model-routing complexity.
4. Prove evidence provenance, malicious input resistance, cross-process fencing, and bounded repair before promoting to unattended multi-project runs.
5. Measure quality/cost and propose self-improvements in shadow mode; promote only after independent holdout testing.

Non-goals: agent swarms, autonomous merges/deployments, cloud infrastructure, unchecked model spend, or rewriting source apps.
