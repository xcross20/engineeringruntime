# Mission

Build a reusable, production-oriented engineering runtime able to take an approved work order from bounded implementation to independently verified acceptance without manual report handoffs. The initial demonstration must reproduce EARS-003's CONTINUE -> one durability repair -> independent rereview -> ACCEPT sequence in a controlled, reproducible fixture. Human authority persists for policy changes, merge, release, spending beyond budget and external effects. Product ACCEPT does not certify harness reliability.
