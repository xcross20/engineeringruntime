# Acceptance policy specification

Only a trusted deterministic Controller may accept. Require verified exact candidate and reviewed SHA, reviewer identity distinct from Builder, isolated worktree, complete mandatory tests, no unresolved material findings, permitted risk fingerprint, bounded execution and verified artifacts. Missing/inconsistent evidence => BLOCKED. In-scope repairable defect with attempts remaining => CONTINUE. Scope/governance ambiguity => RETHINK. All agent statements are untrusted until independently substantiated. Policy changes cannot be written by target code agents.
